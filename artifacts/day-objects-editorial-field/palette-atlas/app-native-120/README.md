# Day Objects app-native palette atlas

This atlas contains 120 static screenshots captured from the Day Objects Lab
on an iPhone 17 Pro Simulator. Every screenshot has ten actors, a unique
deterministic Editorial Field composition, a catalog-backed mesh-gradient
background, and the same Metal renderer used by the Lab MVP. Motion is paused
for direct comparison.

The columns on every contact sheet are the ten palette categories: Pastel,
Vintage, Retro, Neon, Warm, Cold, Spring, Summer, Fall, and Winter.

each contact-sheet thumbnail matches the source screenshot filename.
