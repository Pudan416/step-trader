# Canvas daily chrome review — 2026-09-11

Canvas controls now derive an opaque dark surface, light text and soft accent from the saved daily background palette. This replaces the fixed yellow accent in the Canvas energy pill, data drawer, sound/add controls and shared bottom navigation. Other screens retain their existing color systems.

## Color selection

`TodayCanvasBackdropStore` resolves controls from the same saved pigment source used by Feeds, before snapshot lighting or image sampling. OKLab chroma weights the colored entries; near-gray entries do not wash out the hue. The dominant hue selects a curated sage, blue, lilac or clay family. Dark surfaces adapt by 12% and accents by 18%; an achromatic or balanced input gets neutral tones. Contrast correction preserves readable text and button glyphs. The same input always produces the same output, including reordered palette entries. Palette changes update immediately; restoring the palette through Undo restores the colors. Earning or spending energy does not recolor the UI.

## Layout

Each metric has a label/value line and its own thin progress line. Progress no longer paints under text. Large accessibility text uses stacked titles and values, scaled icon space and the existing scrolling drawer. Controls have opaque tonal backgrounds without glass rims. Existing gestures and the rule that sound/add controls hide while the drawer is open are retained.
