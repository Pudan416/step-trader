# Feeds: яркость и направление градиента

По двум пользовательским снимкам исправлены различия с Canvas:

- Только корневой Feeds использует TodayCanvasBackground(matchesCanvas: true): без чёрного слоя 58% и без дополнительного размытия. Settings/Me сохраняют свою прежнюю подложку.
- Активные карточки идут от тёмного слева к светлому справа. Общий порядок палитры и фон переходов не разворачиваются.
- Цвета карточек берутся из готового растрового Canvas после постобработки, а не из исходных hex палитры. Изображение анализируется один раз при публикации общего снимка на сетке 12×12; крайние 10% по светлоте не доминируют в градиенте. До первого снимка доступна исходная палитра сегодняшнего дня.
- Равномерное затемнение карточек 62% заменено локальным затенением со стороны текста, сходящим к нулю справа.
