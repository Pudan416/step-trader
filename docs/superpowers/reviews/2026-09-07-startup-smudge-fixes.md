# Исправления загрузки экранов и Smudge — 7 сентября 2026

Основа: PR #21, HEAD 7ba05dbd, рабочее дерево current-integration. Существующие локальные художественные эксперименты сохранены; результаты ниже относятся к рабочему дереву, а не к чистому remote HEAD.

## Изменения

- Общий фон: сегодняшняя палитра готова ещё до refresh и первого экспорта; первый render не ждёт debounce. Под TabView лежит лёгкий фон, закрывающий прозрачные промежутки контейнера. При ошибке экспорта сохраняется последняя успешная картинка; идентичный запрос можно повторить без бесконечного цикла.
- Day Objects: шесть pipeline states, sampler и immutable quad переиспользуются между Canvas, постерами и экспортами. Command queues, actor buffers, clocks и состояние сцен остаются раздельными. Подготовка shared Metal ресурсов вынесена из синхронного создания UIView; позднее присоединение renderer использует последнее состояние вкладки, включая паузу. Экспорты также ожидают фоновую подготовку ресурсов.
- Smudge: Metal setup асинхронный. Снимок готовится после layout до касания, после затухания и при смене размера/health/оформления. Ранний ввод ожидает подготовку; при скрытии/демонтаже отложенный ввод очищается. Синхронного GPU wait в production Smudge больше нет. Сброс возрастов выполняется GPU на той же очереди; для CPU-загрузки используется новая base texture, чтобы не перезаписывать ресурс незавершённого кадра.
- Каждый участок Smudge теперь вычисляется в scratch-текстуру и копируется обратно только в границах кисти. Полноэкранных копий пары текстур на каждый участок больше нет. Формулы кисти, ripples, relaxation и разрешение сохранены. Полноэкранный relaxation остаётся: это не обещание нулевой GPU-стоимости эффекта.
- Экспорты виджета объединяются: одновременно идёт один экспорт, очередь хранит только последнее ожидающее состояние. Операция дожидается фоновой записи файла, исключая переупорядочивание записей этой очереди.

## Проверка

Красные тесты подтвердили исходные дефекты: задержка первого фона/пустая палитра, потеря изображения при ошибке и невозможность повторить запрос; отдельные immutable resources каждого renderer; синхронная подготовка Day Objects и Smudge при создании координатора; отсутствие снимка до касания; параллельные экспорты промежуточных состояний виджета.

Итоговый основной прогон: **39 unit/GPU тестов + 1 UI-тест, без ошибок**, `/tmp/perf-final-sim.xcresult`, xcodebuild exit 0. Включены поведение фона и очереди, изоляция mutable buffers, пауза/возврат renderer, подготовка Smudge, водяные круги, Me week stats.

GPU-проверка сравнивает production region-copy с прежним полноэкранным алгоритмом для последовательности пересекающихся и разнесённых штрихов, включая край текстуры. Цвета и поле возраста совпадают побайтно; fixture действительно меняет изображение. `/tmp/perf-sequence-green.xcresult` и итоговый прогон.

Текущие тесты не дают основания обещать конкретный прирост FPS или отсутствие любых задержек. Звуковой тракт в этой правке не изменялся.
