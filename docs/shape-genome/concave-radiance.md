# Concave Radiance

The form begins as a square but treats each edge as a field under inward pressure. Four corners remain legible anchors while the sides retreat toward the center, producing a closed contour that can read as a diamond, a lensing aperture, or a restrained four-point signal. Its identity comes from the relationship between the fixed fourfold order and the variable depth of that pressure.

Seeded variation changes concavity and orientation without changing the family. The same seed must always recover the same silhouette and angle, while nearby seeds should feel like separate appearances rather than animation frames. Rotation is allowed across the full circle so the object arrives with spatial intent instead of inheriting a single emblematic pose.

The Metal implementation should preserve a clean mathematical contour at every scale. Randomness is constrained to a narrow, carefully tuned envelope: enough to make recurrence feel alive, never enough to collapse the waist, imitate a snowflake, or become an ordinary rounded square. This is a meticulously crafted algorithm in which variation serves recognition.

Materials reveal different readings of the same geometry: solid treatments make it a supporting mass, side light turns the inward edges into tension, and luminous contours let it behave as a quiet accent. The final result should feel painstakingly calibrated and masterfully implemented, with the apparent simplicity of the silhouette supported by exact normalization, stable seeding, and disciplined limits.
